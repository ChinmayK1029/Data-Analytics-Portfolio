# EdTech Recorded Lectures Analysis

## Business Problem

An EdTech startup wants to expand its recorded lecture offerings.
The objective of this project is to analyze course data and identify
patterns that can help the company make better decisions.

## Main Focus

The primary focus of this analysis is category-wise performance.

## Tools Used

- Power BI
- Power Query
- DAX

## Analysis

- Category-wise course analysis
- Category-wise average views
- Category-wise ratings
- Instructor performance
- Course duration
- Language analysis
- Course rankings
